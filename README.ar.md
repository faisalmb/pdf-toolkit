# أداة دمج ملفات PDF

[English](README.md) | **العربية**

برنامج سطح مكتب لدمج ملفات PDF والصور، وترتيب صفحاتها، والتوقيع أو الختم أو
الكتابة عليها، ثم حفظها في ملف PDF واحد. الواجهة بلغتين: العربية (من اليمين
لليسار) والإنجليزية (من اليسار لليمين)، ويعمل على ويندوز وماك ولينكس.

مبني بـ Python وPyQt5 وPyMuPDF. الإصدار 11.0.0.

## المزايا

**الملفات والصفحات**
- إضافة ملفات PDF وصور (PNG وJPG وBMP وGIF وTIFF وWebP) بالأزرار أو بالسحب
  والإفلات، وكل صورة تصبح صفحة كاملة.
- نطاق صفحات لكل ملف مثل `1-3,5`، يُتحقق منه أثناء الكتابة.
- معاينة كل الصفحات كمصغّرات، وترتيبها بالسحب أو بأزرار البداية/للخلف/للأمام/النهاية.
- تدوير الصفحات وتكرارها وحذفها، مع التراجع عن آخر حذف.
- إدراج صفحات من PDF آخر أو من صور قبل أي صفحة أو بعدها.
- ترتيب الملفات كاملة، وتعديلاتك على الصفحات تبقى عند إضافة ملفات أو تغيير
  النطاقات أو الترتيب.

**التوقيع والختم والكتابة**
- محرّر تفاعلي يُفتح من قائمة الزر الأيمن على أي صفحة.
- وضع صورة توقيع أو ختم، أو مربع نص. يُحرَّك بالسحب ويُغيَّر حجمه من المقبض في الزاوية.
- خيارات النص: الخط (Helvetica وTimes وCourier والخطان العربيان المدمجان Amiri
  وCairo)، الحجم من 6 إلى 200، اللون، وتعديل المحتوى. النص العربي يُوصل
  ويُرتَّب بشكل صحيح حتى مع الإنجليزية والأرقام.
- **حذف منطقة**: ارسم مستطيلًا فيُحذف فعليًا كل ما بداخله في الملف الناتج
  (وليس مجرد تغطية). المنطقة تُملأ بلون الخلفية المحيطة فلا يبقى مربع أبيض.
- تكبير حتى 400% وتحريك الصفحة بالسحب.
- الأختام تبقى في مكانها الصحيح على الصفحات المدوّرة وبأي مقاس صفحة.

**الحفظ**
- أربع درجات ضغط: بدون، خفيف، متوسط، قوي. تخفّض دقة الصور وجودة JPEG داخل الملف.
- نافذة تقدّم تعرض كل مرحلة (تجميع الصفحات، التواقيع، الضغط، الحفظ) مع إمكانية الإلغاء.
- عند الانتهاء: الحجم قبل وبعد ونسبة التوفير، مع زرّي فتح الملف وفتح المجلد.
- اسم مقترح فريد للملف مثل `PDF_20261101_141210_k3x9.pdf`.
- حفظ آمن: يُكتب ملف مؤقت ثم يُستبدل دفعة واحدة، فلا يبقى ملف ناقص لو توقف البرنامج.

**الراحة والسرعة**
- المصغّرات تُرسم في خيط خلفي منخفض الأولوية فلا تتجمد النافذة، مع بطاقات
  مؤقتة وشريط تقدّم أثناء التحميل.
- شاشة بداية تظهر فور فتح البرنامج.
- كل ملف يُفتح مرة واحدة، والمصغّرات في كاش صغير (حوالي 20 ميجابايت).
- الملفات المحمية بكلمة سر أو التالفة تُرفض عند إضافتها مع ذكر السبب.

## التنزيل والتثبيت

الحزم الجاهزة تُنشر تلقائيًا في صفحة **Releases** مع كل تحديث
(انظر [البناء التلقائي](#البناء-التلقائي-github-actions)).

| النظام | الملف | التثبيت |
|---|---|---|
| ويندوز 10/11 (x64) | `PDFMerger-Setup-11.0.0.exe` | شغّله؛ يثبّت للمستخدم الحالي بدون صلاحيات مدير |
| ماك (Apple Silicon) | `PDFMerger-11.0.0-macOS-arm64.dmg` | افتحه واسحب **PDFMerger** إلى **Applications** |
| لينكس (x86_64) | `PDFMerger-11.0.0-linux-x86_64.tar.gz` | فك الضغط ثم شغّل `./install.sh` |

### ملاحظات ويندوز
- يثبّت في `%LOCALAPPDATA%\Programs\PDF Merger` مع اختصار في قائمة ابدأ
  (واختياريًا على سطح المكتب) وإزالة من "التطبيقات المثبّتة"، وواجهة التثبيت
  بالعربي أو الإنجليزي.
- البرنامج مبني كمجلد عادي (وليس ملفًا واحدًا يفك نفسه) وبدون ضغط UPX، وهذا
  يتجنب أشهر سبب لاعتبار Windows Defender برامج بايثون مشبوهة خطأً.
- ملف التثبيت غير موقّع رقميًا، فقد يظهر **SmartScreen** ("Windows protected
  your PC") بعد تنزيله من الإنترنت: **More info** ثم **Run anyway**. وإن كان
  **Smart App Control** مفعّلًا في ويندوز 11 فإنه يمنع البرامج غير الموقّعة بلا خيار تجاوز.
- الحل النهائي: توقيع رقمي (مثل Azure Trusted Signing أو شهادة Code Signing)
  أو النشر في Microsoft Store. ولو اعتبره Defender مشبوهًا خطأً يمكن إرساله
  للمراجعة عبر <https://www.microsoft.com/wdsi/filesubmission>.

### ملاحظات ماك
- التطبيق غير موقّع من Apple، فأول مرة: كليك يمين على **PDFMerger** في
  Applications ← **Open** ← **Open**.
- البناء التلقائي لأجهزة Apple Silicon. لأجهزة Intel ابنِه على جهاز Intel بـ `./build_mac.sh`.

### ملاحظات لينكس
- `install.sh` يثبّت في `~/.local/share/pdfmerger` ويضيفه لقائمة التطبيقات
  بدون `sudo`. للإزالة: `./uninstall.sh`.
- يحتاج مكتبات Qt/X11 المعتادة في التوزيعات المكتبية. لو لم يفتح على Ubuntu/Debian:
  ```bash
  sudo apt install libxcb-xinerama0 libxkbcommon-x11-0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0
  ```

## طريقة الاستخدام

1. **أضف الملفات**: زر **إضافة ملفات** أو **إضافة صور كصفحات**، أو اسحبها إلى النافذة.
2. **حدّد النطاق** (اختياري): اختر الملف في لوحة الملفات وحدّد نطاق صفحاته
   (الافتراضي كل الصفحات).
3. **رتّب الصفحات**: اسحب المصغّرات، أو حدّد صفحة واستخدم أزرار الترتيب أسفل المعاينة.
4. **عدّل الصفحات**: الزر الأيمن على الصفحة للتدوير أو التكرار أو الحذف أو
   الإدراج قبلها/بعدها أو **توقيع / ختم / كتابة**. الصفحات التي عليها أختام تظهر بعلامة ✍️.
5. **اختر درجة الضغط** من الشريط.
6. **احفظ**: اختر المكان، تابع التقدّم، ثم افتح الملف أو المجلد.

زر اللغة في الأعلى يبدّل بين العربية والإنجليزية فورًا مع اتجاه الواجهة.

## التشغيل من الكود المصدري

يحتاج Python 3.10 أو أحدث:

```bash
pip install -r requirements.txt
python launcher.py      # مع شاشة البداية
# أو
python main_app.py      # النافذة الرئيسية مباشرة
```

المكتبات (`requirements.txt`): PyQt5 وPyMuPDF وarabic-reshaper وpython-bidi.

## بناء الحزم

PyInstaller لا يبني لنظام آخر، فكل حزمة تُبنى على نظامها. كلها تستخدم
[`PDFMerger.spec`](PDFMerger.spec) (بناء مجلد onedir بدون UPX).

| النظام | الأمر | الناتج |
|---|---|---|
| ويندوز | `build_exe.bat` | `installer_output\PDFMerger-Setup-11.0.0.exe` و`dist\PDFMerger\` |
| ماك | `./build_mac.sh` | `installer_output/PDFMerger-11.0.0-macOS-<arch>.dmg` و`dist/PDFMerger.app` |
| لينكس | `./build_linux.sh` | `installer_output/PDFMerger-11.0.0-linux-<arch>.tar.gz` و`dist/PDFMerger/` |

- **ويندوز**: برنامج التثبيت يحتاج [Inno Setup 6](https://jrsoftware.org/isinfo.php)
  (`winget install JRSoftware.InnoSetup`)، وبدونه يُبنى مجلد البرنامج فقط.
- **ماك**: يحتاج Pillow (السكربت يثبّتها) لتحويل `app_icon.png` إلى أيقونة `.icns`.
- أبقِ مجلد `fonts/` بجانب ملف البناء. لو غاب لن يفشل البناء، لكن الخطوط العربية لن تُضمَّن.

### البناء التلقائي (GitHub Actions)

[`.github/workflows/build.yml`](.github/workflows/build.yml):
- **كل push إلى `main`** يشغّل الاختبارات، ثم يبني الحزم الثلاث وينشرها في
  GitHub Release جديد بوسم `v11.0.0-build.<رقم التشغيل>`، ويصبح هو الأحدث.
- رفع وسم إصدار (`git tag v11.0.0 && git push origin v11.0.0`) ينشر إصدارًا
  باسم هذا الوسم.
- الـ pull request يشغّل الاختبارات فقط، والـ commit الذي يغيّر ملفات `.md`
  فقط لا يشغّل البناء.
- أو يدويًا من **Actions ← build ← Run workflow** (الحزم تظهر كـ Artifacts بدون إصدار).
- رقم الإصدار يُقرأ من `APP_VERSION` في `PDFMerger.spec`.

## كيف يعمل

- **الواجهة منفصلة عن المحرك**: `pdf_engine.PdfEngine` بلا أي عناصر Qt. النافذة
  تبني قائمة مراجع صفحات (الملف، الصفحة، الدوران) وأختام، وتسلّمها للمحرك.
- **قفل واحد لـ PyMuPDF**: المكتبة لا تتحمّل العمل من خيطين، فكل وصول للملفات
  يمر عبر قفل واحد يبقى طوال عملية الدمج.
- **المصغّرات**: خيط `ThumbnailWorker` يعالج طابور مهام، يرسم كل صفحة كبكسلات
  خام بحجمها النهائي ويحوّلها إلى `QImage` داخل الخيط، مع كاش LRU من 200 عنصر.
- **تعديلات لا تضيع**: لكل بطاقة صفحة معرّف ثابت، وإضافة الملفات أو تغيير
  النطاقات يحدّث صفحات الملف المعني فقط، فيبقى الدوران والتكرار والترتيب والأختام.
- **الأختام**: مواضعها محفوظة كنسب من مقاس الصفحة، وعند الحفظ تمر عبر مصفوفة
  إلغاء الدوران للصفحة فتقع في مكانها الصحيح على الصفحات المدوّرة.
- **الضغط**: `rewrite_images` من PyMuPDF يعيد ترميز الصور الأعلى من الدقة
  المستهدفة فقط، وحجم "قبل" يُقدَّر من جدول الكائنات فيُحفظ الملف مرة واحدة.
- **النص العربي**: يُجهَّز بـ `arabic-reshaper` و`python-bidi` ثم يُكتب بخط Amiri أو Cairo مضمّن.

## الاختبار

`test_headless.py` يشغّل البرنامج الحقيقي بدون شاشة ويتصرف كمستخدم: يضيف ملفات
سليمة وخاطئة، يحدّد النطاقات، ينتظر المصغّرات، يدوّر ويكرّر ويحذف ويتراجع،
يتحقق أن التعديلات تبقى بعد إعادة المزامنة، يدمج بكل درجات الضغط، يطبّق أختام
صور ونصوص وعربي (منها على صفحات مدوّرة)، يجرّب حذف المنطقة وإلغاء الدمج ورفض
الملفات المحمية وتبديل اللغة.

```bash
python make_test_fixtures.py
QT_QPA_PLATFORM=offscreen python test_headless.py
```

في PowerShell على ويندوز: `$env:QT_QPA_PLATFORM="offscreen"; python test_headless.py`.
ينتهي التشغيل الناجح بـ `=== كل الاختبارات نجحت ===`.

## سجل الإصدارات

- **v11**: التعديلات لا تضيع عند إضافة ملفات أو تغيير النطاقات، التراجع يعيد
  الصفحة بأختامها، وصول آمن لـ PyMuPDF من عدة خيوط، مصغّرات أخف وحفظ واحد عند
  الضغط، أختام صحيحة على الصفحات المدوّرة، شريط أدوات ورسائل ونافذة تقدّم
  وبطاقات تحميل وشاشة بداية جديدة، برنامج تثبيت ويندوز يتجنب إنذارات Defender
  الكاذبة، ونسخ ماك ولينكس.
- **v10**: إصلاح الملف الفارغ ("insufficient data for an image") عند الضغط
  باستخدام `rewrite_images`، وأزرار ترتيب بنصوص واضحة بدل الأسهم.
- **v9**: أزرار ترتيب الصفحات، النقر المزدوج لتعديل النص، حذف منطقة يحافظ على لون الخلفية.
- **v8**: خطوط عربية مدمجة، حذف منطقة (redaction)، التحريك بالسحب عند التكبير.
- **v7**: الأختام المتعددة لم تعد تتكدس، تكبير في المحرّر، اسم ملف مقترح فريد، زر "حفظ".
- **v5**: شريط درجات الضغط، الصور كصفحات، الإدراج في أي موضع، محرّر التوقيع/الختم/الكتابة.
- **v4**: واجهة عربي/إنجليزي، نسبة ضغط حقيقية، هوية بصرية جديدة وشريط حالة.
- **قبلها**: المصغّرات والدمج في الخلفية، الحفظ الآمن، فحص الملفات مبكرًا، التراجع، فصل المحرك عن الواجهة.
